# README 演示图来源

- 来源：HUD 1.3.0 的 `overlay/HUDView.m` 与内置语言包；不是 HTML 概念稿，不是实时屏幕录像。
- 所有数值、比例、任务名及趋势点都是合成示例。不调用采样器、账户接口或本机会话扫描，不读取用户偏好、额度、任务或账单。
- 每种语言包含主页、Codex、电脑性能三张 PNG；GIF 是这三张页面各停留三秒的轮播。
- 离屏 PNG 不具备桌面背景的实时材质合成。渲染器将原生语义文字颜色在 Dark Aqua 下解析为静态色，保留原生布局与控件；真实桌面透明效果取决于背景与用户设置。
- macOS 原生页面仅示意 macOS 体验，不冒充 Windows 实机截图。未展示的模块仍然保留在软件中。
- 复现：在 macOS 15+、安装 Xcode Command Line Tools 后，从仓库运行 `zsh docs/tools/render-readme.sh`。临时文档渲染程序不会安装、置顶或替换 HUD，不写用户设置；输出只写入此目录。
- 这些图片用于项目文档，沿用仓库 MIT 许可证。生成脚本不属于应用运行路径，不增加常驻资源负担。
