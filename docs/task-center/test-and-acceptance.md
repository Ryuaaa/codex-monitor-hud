# 资源、生命周期与 P1 验收方案（P0）

## 测试风险地图

| 高影响失败 | 最便宜的可靠检查 | P1 门槛 |
|---|---|---|
| 修改或泄露正式任务 | Rust 路径/权限单测 + 合成夹具 + 只读实样本检查 | 必须通过 |
| 坏文件拖垮全部视图 | 单文件/单行损坏夹具与集成测试 | 必须通过 |
| `notLoaded` 被误报未运行 | 四状态纯映射单测 | 必须通过 |
| 关闭后残留进程 | 同一构建产物 20 次启动—关闭 PID 检查 | macOS 必须实测；Windows 分开报告 |
| 任务中心故障影响 HUD | 启动前记录 HUD PID，强制结束任务中心，再确认 HUD PID/响应 | macOS 必须实测；Windows 分开报告 |
| 正文被首页预加载/缓存 | 命令调用测试与产物扫描 | 必须通过 |
| UI 核心流程回归 | 组件测试：项目、看板、列表、搜索、详情 | 必须通过 |

## 资源基线方法

1. 使用同一台机器、同一 HUD 构建、相同可见模块和采样周期。
2. 先测 HUD 独立运行至少 10 分钟，记录 CPU、RSS、唤醒次数和能耗指标的中位数、四分位范围与最小/最大值。
3. 重复三轮，形成基线区间；不预设百分比阈值。
4. 分别测任务中心从未打开、打开空闲、加载任务、关闭后 2 分钟；用相同命令和窗口长度比较。
5. 只有关闭后的 HUD 指标落回重复基线波动区间，才可称“无可辨别常驻影响”。

## 生命周期与故障注入

- 生产构建不监听 TCP/UDP 端口；启动后用 `lsof -Pan -p PID -i` 检查。
- 20 次循环：启动应用，等待主窗口出现，发送正常关闭，5 秒内应用 PID 及其后代全部消失。
- 强制结束任务中心，确认 HUD 原 PID 仍存在且诊断命令可响应。
- 用合成坏 Markdown、超大正文、坏 JSONL、权限拒绝和不存在目录验证局部错误。
- WebView 崩溃需平台专用注入；若无法自动化，标为未验证，不用普通关闭替代。

## P2 安全写入风险图与门槛

| 风险 | 影响 | 必须验证的失败路径 | macOS 当前状态 |
|---|---|---|---|
| 数据丢失/无关格式重写 | 最高 | 原文、未知字段和正文逐字保留；失败恢复原任务与原事件 | 已验证 |
| 覆盖并发更新 | 最高 | 预览后修改文件，确认必须返回冲突且保留草稿 | 已验证 |
| 错误状态映射 | 最高 | 只允许正式五状态；拒绝 Dashi 独有状态 | 已验证 |
| 事件与当前状态不一致 | 最高 | 事件准备、提交、回读各阶段失败；回滚精确比较 | 已验证（断电间隙仍属剩余风险） |
| 隐私字段泄露 | 最高 | 受限记录拒绝跨 Rust 边界；错误只含固定诊断，不含正文 | 已验证 |
| 非法或损坏任务 | 高 | 坏分隔符、坏 YAML、只读、超限与非法值在写前停止 | 已验证 |
| UI 误写 | 高 | 页面打开零写；取消零写；确认才调用 apply；冲突/失败保留草稿 | 已验证（真实窗口主观流程待用户） |
| P1 与生命周期退化 | 高 | 看板/列表/搜索/按需正文；20 次退出；端口、HUD 隔离 | 自动回归已验证；真实窗口点击沿用 P1 证据 |

所有写测试使用 Rust 临时目录或前端合成 Provider。正式任务目录只运行只读诊断，并在前后比较文件元数据快照；禁止把正式任务作为写测试目标。
