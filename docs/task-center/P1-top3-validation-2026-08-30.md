# P1 前三项能力验证（2026-08-30）

## 结论

标签与保存筛选、显式任务关系、评论与人工活动已经形成可独立验收闭环。当前结果只说明功能和自动安全验证完成；在正式签名、公证、旧版本升级和 GitHub Release 完成前，不称为已发布。

## 已实现

| 能力 | 权威位置 | 安全边界 |
|---|---|---|
| 标签与保存筛选 | 标签在任务 Markdown；筛选在应用配置 | 筛选不保存搜索词或任务内容；配置可删除重建 |
| 父子、阻塞、相关关系 | 当前任务 Markdown 的 `parent_id`、`blocked_by_ids`、`related_ids` | 一次操作只改当前任务；反向关系在内存推导 |
| 评论与人工活动 | 月度 JSONL 追加事件 | 不改任务 Markdown；任务和事件双哈希；预览、确认、回读、冲突停止 |
