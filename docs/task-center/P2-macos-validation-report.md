## 实现范围

- 新建正式最小字段任务。
- 编辑标题、正式任务状态、优先级、日期型截止日期、负责人、关联任务。
- 通过 `record_status: archived/current` 归档和恢复，不移动任务文件。
- 所有操作遵循：写前预览、用户明确确认、SHA-256 期望版本、冲突停止、同目录准备、原子替换、事件追加、任务与事件回读、失败回滚。
- 写入只由界面命令触发；无后台、定时、启动修复、服务、端口或第二套业务数据库。
- 不支持字段明确显示“正式结构暂不支持”，不私存。

## 风险与限制

- Markdown 与 JSONL 是两个文件，文件系统不提供跨文件原子事务；实现采用各自原子替换、写后核对和恢复副本。进程或机器在极窄的两文件提交间隙被硬断电，仍需后续恢复诊断；本阶段不以“绝对不会不一致”表述。
- 当前只允许日期型截止日期；带时间与时区的扩展需先审核正式结构。
- 同一 P2 功能已同步到 Windows 共享代码并通过原生 CI；Windows 人工桌面视觉、200% 缩放、资源基线、HUD 共存与定向 WebView2 崩溃仍按用户决定暂缓，详见 `P2-windows-ci-evidence-2026-08-24.md`。
