# 隐私与按需加载规则（P0）

1. 默认允许根目录只包含明确配置的正式任务目录与对应事件目录。路径须先规范化并验证仍位于允许根目录；拒绝符号链接逃逸、任意绝对路径和 `..`。
2. 首页扫描每个 Markdown 最多 128 KiB，只读取成对 `---` 之间的 frontmatter；不得读取正文或附件。
3. `privacy: general` 且 `codex_access` 不是 `forbidden`、`explicit_only` 时才进入 P1 展示。缺失、`pending_classification` 或未知隐私值按受限处理。
4. 正文仅在用户明确打开某一已显示任务详情后读取，最大 2 MiB；不跟随附件或 Wiki 链接。
5. 事件只在任务详情打开后加载；逐行解析，坏行隔离，日志只记录文件名、行号和错误类别，不记录事件正文或敏感字段。
6. P1 不扫描私密档案库，不接触绝密保险箱，不读 Cookie、令牌、会话密钥或浏览器数据。
7. 搜索仅作用于已加载的允许元数据；正文不进入搜索索引。P1 不建立持久缓存或第二数据库。
8. 错误日志不得包含 frontmatter 原文、正文、source refs 全量、绝对私密路径或事件载荷。
9. 合成夹具覆盖 `general`、`explicit_only`、`forbidden`、坏 YAML、坏日期和坏 JSONL；自动测试不得依赖正式资料。
