# 隐私与按需加载规则（P0）

0. 默认首页只读取官方 Codex 任务列表，不检测个人正式任务目录；正式任务元数据仅在用户进入“管理任务”后读取。创建本地任务库必须由用户明确点击触发。
1. 默认允许根目录只包含明确配置的正式任务目录与对应事件目录。路径须先规范化并验证仍位于允许根目录；拒绝符号链接逃逸、任意绝对路径和 `..`。
2. 首页扫描每个 Markdown 最多 128 KiB，只读取成对 `---` 之间的 frontmatter；不得读取正文或附件。
3. `privacy: general` 且 `codex_access` 不是 `forbidden`、`explicit_only` 时才进入 P1 展示。缺失、`pending_classification` 或未知隐私值按受限处理。
4. 正文仅在用户明确打开某一已显示任务详情后读取，最大 2 MiB；不跟随附件或 Wiki 链接。
5. 事件只在任务详情打开后加载；逐行解析，坏行隔离，日志只记录文件名、行号和错误类别，不记录事件正文或敏感字段。
6. P1 不扫描私密档案库，不接触绝密保险箱，不读 Cookie、令牌、会话密钥或浏览器数据。
7. 搜索仅作用于已加载的允许元数据；正文不进入搜索索引。P1 不建立持久缓存或第二数据库。
8. 错误日志不得包含 frontmatter 原文、正文、source refs 全量、绝对私密路径或事件载荷。
9. 合成夹具覆盖 `general`、`explicit_only`、`forbidden`、坏 YAML、坏日期和坏 JSONL；自动测试不得依赖正式资料。
10. Codex 历史只在用户点击某一绑定对话的“读取历史”后请求；首页和任务详情打开过程均不自动连接。轮次分页固定使用 `itemsView: "notLoaded"`，仅向前端返回编号、状态和时间等元数据。
11. `thread/read` 的官方响应可能携带任务预览字段；Rust 适配器必须在进程边界内丢弃该字段，不展示、不记录、不缓存。接口失败不得回退为一次性读取完整历史。
12. 官方历史请求使用短期 `codex app-server` 子进程，请求完成、失败或超时后均须结束并回收；不得演变为任务中心关闭后仍存在的服务或连接。
13. 默认 Codex 活动列表通过 `thread/list` 每页最多读取 25 条交互式任务，优先启用 `useStateDbOnly`，不扫描对话正文。Rust 边界只允许任务编号、用户设置名称、来源、状态、时间、置顶标记和工作目录末级名称通过；必须丢弃 `preview` 与完整 `cwd`。
14. Codex 列表失败与正式任务库失败互相隔离；任何一方失败不得触发另一方的隐式读取、创建或写入。
15. 已保存筛选只允许项目编号、正式状态、单个标签、归档开关和视图类型；不得保存搜索文字、任务标题、正文、负责人、对话内容或完整路径。配置文件限制为 128 KiB、最多 32 项，拒绝符号链接和未知版本。
16. 评论与人工活动只在用户打开任务详情、填写内容、生成预览并再次确认后追加；预览绑定当前任务哈希和当月事件文件哈希。内容最多 2000 字，记录人最多 120 字；非评论事件的任意 `message` 字段不得跨 Rust 边界传给界面。
17. 父子和阻塞关系只写当前任务的正向字段；反向关系仅由已经允许读取的任务元数据在内存中推导，不批量读取正文，也不因一次关系编辑改写其他任务。
