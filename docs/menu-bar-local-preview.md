# macOS 菜单栏本机试用构建

日期：2026-09-19。基于 1.3.0，安装包内部构建号 30.2；不是新的 GitHub 正式版。源代码版本号未升级，Windows 未改动。

## 已实现

- 原生 NSStatusItem + 按需 NSPopover，不引入浏览器或另一套后台进程。
- 默认保留原悬浮窗并增加菜单栏图标、周剩余额度；设置改为“显示顶部菜单栏”和“显示屏幕悬浮窗”两个独立勾选项，可同时显示。
- 至少保留一个入口：只剩一种显示方式时，该勾选项会暂时锁定；先开启另一种即可再关闭。已有 `displayMode` 设置不变，无需迁移。
- 顶部最多两项：周额度、5 小时额度、CPU、内存；第一/第二项控制顺序，去重，可仅显示图标。
- 点击详情显示已启用的额度、Token/费用、任务活动、最近 5 条历史和电脑状态；历史不等于正在运行。
- 详情始终保留设置、显示悬浮窗、任务中心、退出入口，长内容可滚动。
- 顶部额度选择不依赖悬浮窗额度卡片是否开启；额度表示剩余，CPU/内存表示占用。
- 旧值标 `*`，不可用/已过期标 `—`，真实 0% 保留。复用既有定时器在周期过期时更新显示，不为此提前查询账户。
- 不重复创建采集器或计时器；详情关闭释放视图。在仅菜单栏模式且未选择 CPU/内存、未开启历史时，不因隐藏主页启动系统采样。
- 不改变已保存的悬浮窗位置、大小或模块选择；从仅菜单栏恢复悬浮窗会恢复必要采样。
- 新文本覆盖简中、繁中、英文、日文、韩文。面板不播放开合动画。

## 对抗式审查及验证

| 风险 | 验证 / 处理 |
|---|---|
| 隐藏后失去入口 | 两个勾选项不能同时关闭；图标模式始终保留；设置/退出按钮存在；三种模式的图标和窗口行为使用无前台窗口的替身验证 |
| 旧额度冒充当前值 | 固定样例覆盖 live、previous、读取失败、超过 15 分钟、周期重置、真实 0、无效数值 |
| 重复采集及常驻资源增加 | 同一 provider 只启动一次；旧定时器失效；局部过期不产生新账户请求；关闭详情释放视图 |
| 多语言截断及长列表不可达 | 五种语言原生离屏布局；换行标签宽高、底部历史可滚达均检查 |
| 改显示方式破坏原功能 | 原有界面、缩放、模块隐藏、计算逻辑回归通过 |

运行：`sh tests/test-menu-bar.sh`。每种语言 63 个断言通过，全部使用合成数据和替身，不启动正式应用生命周期，不读取会话或真实账户。截图只用于测试，非真实账户证明。

另已通过：Apple 芯片/Intel 双架构编译，`--ui-diagnostic`、`--logic-diagnostic`、`ruby tests/test-localizations.rb`、`git diff --check`。本机安装包 Developer ID 签名验证通过，与构建包二进制 SHA-256 一致，正常运行且原 HUD 数据仍显示。
