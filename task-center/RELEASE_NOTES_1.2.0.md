# Codex Monitor 任务中心 1.2.0

这是任务中心首个正式公开版本，独立于 24 小时常驻 HUD，只有打开时才运行。

## 新增

- 标签展示、标签筛选与可保存的结构化筛选方案；不保存搜索文字或任务内容。
- 父任务、子任务、阻塞与相关任务；反向关系只在内存推导，一次操作只改当前任务。
- 评论和人工活动；只追加正式 JSONL 事件，不改任务 Markdown。
- 独立安全更新通道；每天至多自动检查一次，也可手动检查和一键安装。

## 安全与兼容

- 所有任务写入仍需预览、明确确认、并发版本检查和写后回读；冲突不会覆盖。
- 默认首页只读取官方 Codex 任务元数据；正文、事件和完整历史继续按需加载。
- macOS 通用包同时支持 Apple Silicon 和 Intel，使用 Developer ID 签名并通过 Apple 公证。
