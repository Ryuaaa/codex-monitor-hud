# Codex Monitor 任务中心 1.4.0

本版在保留 1.3.0 官方任务读取、准确打开、安全继续和可选任务管理能力的基础上，加入新手说明、完整显示自定义，以及可预览、可恢复的全局运行配置。

## 新增

- 首次启动显示三步新手说明，之后可通过右上角“？”随时重看。
- 支持深蓝、中性深色、浅色和高对比主题，并可自定义强调色、字体、字号、内容密度、行距和动态效果。
- 可针对当前列表、全部未归档任务或全部任务，分别选择标准/Fast速度和推理强度。
- 推理强度选项从本机 Codex 当前模型能力动态读取，也可按每个模型选择默认、最低或最高强度。
- 批量修改前显示任务数量、模型分布、不支持项和影响范围；再次确认后才写入，并可恢复上次修改前的配置。

## 运行边界

- 显示设置只保存在本机，不增加后台读取、轮询或常驻服务。
- 全局运行配置只在用户打开设置页或明确确认修改时短暂启动本机官方接口，完成后立即退出。
- 正在运行的回合不会被改变；新配置只用于后续回合。
- Fast速度会在以后从任务中心继续任务时再次带入；直接在 Codex 中继续时，以 Codex 当时的设置为准。
- 应用只读取任务编号、模型和运行配置等必要元数据，不读取、展示或保存对话正文、命令正文、工具输出或认证信息。

## 验证

- 前端 42 项测试、Rust 59 项测试、前端生产构建、Rust格式检查及严格静态检查通过。
- 已验证显示设置即时预览与持久化、全局速度和推理强度独立选择、修改前预览、确认写入与恢复路径。
- 已在 macOS 上完成浏览器视觉检查和原生应用启动检查；关闭后无任务中心、开发服务器或浏览器测试进程残留。
- 正式发布包同时支持 Apple Silicon 与 Intel，并使用 Developer ID 签名和 Apple 公证。
