# Codex Monitor 任务中心 1.3.0

本版在保留 1.2.1 全部任务管理能力和独立更新通道的基础上，加入官方 Codex 任务继续执行与准确打开。

## 新增

- 从官方任务详情输入后续要求，经第二次明确确认后，在原 Codex 任务中启动新一轮执行。
- 显示启动、运行、等待简单审批、完成、失败和中断状态；支持主动停止本次执行。
- 通过 `codex://threads/<任务编号>` 在 Codex 桌面版准确打开所选任务；链接不可用时，回退为打开 Codex 并复制任务编号。

## 低负担与隐私

- 继续任务时使用官方 `thread/resume` 与 `turn/start`，恢复阶段不加载完整对话历史。
- 任务中心不展示、记录或持久化对话正文、命令正文、工具输出、终端输入或认证信息。
- 只为当前操作短暂启动本机官方接口；任务完成、失败、中断或任务中心退出后关闭对应子进程。
- 看板故障或官方接口退出只会让本次继续任务失败，不会影响 HUD 常驻监控。

## 验证

- 已在 macOS 上完成真实官方任务的新建、首轮完成、从任务中心续接、完成事件接收和自动归档。
- Rust 52 项、前端 38 项、前端生产构建和严格静态检查通过。
- 原生调试版加载 25 个官方任务后空闲 CPU 为 0.0%，无监听端口、无常驻 app-server，退出后无残留进程。
- macOS 通用包同时支持 Apple Silicon 与 Intel，并使用 Developer ID 签名和 Apple 公证。
