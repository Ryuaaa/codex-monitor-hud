# Codex Monitor 任务中心 1.2.1

这是 1.2.0 的更新可靠性修正版，保留标签与筛选、任务关系、评论与人工活动等全部功能。

## 修复

- macOS 更新检查和下载按需读取当前系统 HTTPS 代理，代理关闭时继续使用原有直连路径。
- 更新清单改用 GitHub 官方资产接口，降低部分网络环境直连下载页失败的概率。
- 区分下载中断、签名验证失败和安装替换失败；任何失败都保持原版本不变。

## 安全与兼容

- 只在用户检查或安装更新时读取系统代理地址，不保存代理配置，不读取账号、Cookie 或任务正文。
- 更新包仍须通过独立签名验证；安装前再次核对用户看到的精确版本。
- macOS 通用包同时支持 Apple Silicon 和 Intel，使用 Developer ID 签名并通过 Apple 公证。
